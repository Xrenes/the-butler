THE BUTLER — BRAND ASSET KIT
Brand: The Butler (app, Telegram bot, web/PWA)
Colors: navy #101727; tux white #FFFFFF; bow tie red #E00012.

RECOMMENDED FILES:
Telegram bot profile photo: telegram-bot-avatar-512.png (512x512, square)
PWA/Android install icon: icon-192.png and icon-512.png
Android adaptive icon: android-adaptive-foreground-432.png + android-adaptive-background-432.png
Apple home screen: apple-touch-icon.png (180x180)
Apple App Store / large app master: app-store-icon-1024.png (1024x1024 RGB/RGBA PNG)
Browser favicon: favicon.ico, icon-16.png, icon-32.png, icon-48.png and the-butler-icon.svg
Google Search/favicon: google-search-favicon-48.png (also SVG is suitable)
Social link preview: open-graph-1200x630.png, twitter-card-1200x600.png
Transparent master: the-butler-icon-transparent.svg, logo-transparent-1024.png
Web header: the-butler-wordmark.svg or .png

INTEGRATION:
Copy asset files to your website /public/icons/ directory and paste WEB_HEAD_SNIPPET.html tags inside <head>.
Replace the example YOUR-DOMAIN.example with your actual site domain for OG tags.
Web manifest uses relative /icons paths, change if hosting elsewhere.
Telegram: upload the 512x512 avatar using BotFather /setuserpic.
Google search result favicon usually comes from the site's icon; indexing/crawling controls when updates appear.

NOTE: The icon is clean vector artwork based on the chosen tuxedo concept, maintaining the same navy/white/red identity. Only the bow tie is red. Transparent versions are best on dark-colored surfaces.
